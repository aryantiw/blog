# Scientifically Yours

A framework-free HTML, CSS, and JavaScript migration of [naturenspace.blogspot.com](https://naturenspace.blogspot.com/), ready for GitHub Pages at `https://aryantiw.github.io/blog/`.

Add a Markdown file to `posts/`, add its metadata between the frontmatter markers, run `npm run build`, and push. GitHub Actions regenerates `posts.json` automatically.
